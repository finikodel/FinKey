# FinKey — исходный проект Android Studio

**Платформа:** Android 10+ (API 29+), Kotlin, Android Input Method Service.
**Идентификатор:** `com.finikodel.finkey`
**Начальная версия:** 1.0.0 (versionCode 1).

## Открытие
1. Распакуй ZIP.
2. Android Studio → Open → выбери папку `FinKey_FullSource`.
3. Дождись Gradle Sync. При первом открытии нужны интернет и установленный Android SDK / JDK 17.
4. Build → Build Bundle(s) / APK(s) → Build APK(s).
5. Debug APK будет в `app/build/outputs/apk/debug/app-debug.apk`.

## Что уже есть в исходниках этого снимка
- Android-проект и регистрация системной клавиатуры IME.
- Рабочая базовая экранная клавиатура с буквами, переключением RU/EN, пробелом, удалением и Enter, удалением и Enter.
- Первичный выбор языка, onboarding, системное включение/выбор клавиатуры.
- Разделы настроек клавиатуры, темы, переключатели звуков/эффектов/вибрации, Mini Pet, расширений, пользовательских клавиш и ввода.
- Экран FinKey Catalog и входа (пока без подключённого облачного API).
- Экран «О приложении»: Created by Finikodel и версия из BuildConfig.
- OTA-клиент: проверка JSON-манифеста, скачивание APK, SHA-256 проверка и вызов системного установщика.
- SQL-основа Supabase для профилей, ресурсов, лайков, комментариев и сохранений.

## Честный статус
Это расширенный исходный каркас, а не завершённая реализация всего запрошенного продукта. Не подключены Supabase URL/ключи и OAuth, не настроены Storage policies и реальный сервер обновлений, а некоторые разделы настроек пока объясняют будущие функции вместо того, чтобы реализовывать их. В клавиатуре ещё нет полноценного словаря, автокоррекции, предиктивного ввода, жестового ввода, редактора тем, загрузчика Mini Pet и пользовательских расширений. Не устанавливай это как готовый релиз и не распространяй APK до тестирования.

## Проверка IME
1. Установи debug APK.
2. Открой FinKey → «Включить FinKey».
3. В системных настройках включи FinKey.
4. Вернись → «Выбрать FinKey» → выбери FinKey.
5. Открой поле ввода в тестовом приложении.

## Обновления всем пользователям
Подробная инструкция находится в `backend/README_RU.md`. Коротко: подписанный release APK загружается в публичное HTTPS-хранилище, затем обновляется JSON-манифест. У всех установленных пользователей кнопка проверки обращается к этому манифесту. Установка требует системного подтверждения Android.

**Подпись:** перед первым публичным релизом создай release keystore в Android Studio и сохрани его резервную копию. Для всех будущих APK используй тот же ключ.
